# FLAMETOR

### Professional Photo Editing for macOS

**FLAMETOR 1.0** is a free, standalone photo-editing application for macOS, designed for photographers who want a straightforward workflow and precise control over their images.

## Features

- Exposure, contrast and tonal adjustments
- White balance and colour correction
- HSL colour mixer
- Tone curves and histogram
- Film-inspired presets
- Linear gradient adjustments
- Cropping and zoom
- Save and reopen FLAMETOR projects
- Professional and batch photo exporting

## Installation

1. Download the FLAMETOR ZIP file from Releases.
2. Double-click the ZIP to extract the application.
3. Move FLAMETOR into your Applications folder.
4. Open FLAMETOR.

**Security notice:** Apple notarisation has not been confirmed for this independently distributed application. macOS may prevent it from opening. Only if you trust the download, follow Apple's instructions in System Settings → Privacy & Security → Open Anyway, if available. Do not disable macOS security protections.

## Privacy
